Choose candidate search terms from the visitor's theme and audience. Search two complementary terms if a theme has several meanings. Get individual records and discard objects where the connection depends on an unsupported assumption.

Return a shortlist in a deliberate sequence. For each, give the object ID and collection link, maker or culture as recorded, material, date and the evidence for its inclusion. Label a speculative teaching question as a question. Mention a gallery only if supplied by the museum. For image reuse, link a file only when the record marks it public domain. Close by identifying the strongest comparison for this particular audience.
